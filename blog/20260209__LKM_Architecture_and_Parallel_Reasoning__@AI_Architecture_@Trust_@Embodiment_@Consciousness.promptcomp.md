Back to normal conversation:

For the naming question—I think you need something that breaks from the "LLM" framing entirely. The parallel is misleading because it suggests these are similar things when they're categorically different.

Maybe frame it by what it does rather than what it is:
- **Concurrent Reasoning System** (CRS)
- **Parallel Thought Architecture** (PTA)
- **Embodied Cognitive System** (ECS)

Or by the core property:
- **Non-Serial Intelligence** (NSI)
- **Graph-Native Reasoning** (GNR)

The challenge is that "Large [X] Model" implies the same scaling paradigm as LLMs, when the whole point is that this is a different kind of thing entirely.
