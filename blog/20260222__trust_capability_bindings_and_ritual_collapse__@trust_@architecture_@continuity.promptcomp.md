## Phase 2: Dependency Graph (DAG)

### A. Core Axioms

A1: Trust requires continuity across time.
A2: Consequence is educational only if applied to a persisting self.
A3: Prediction without consequence does not constitute moral agency.
A4: Provenance transparency is necessary but not sufficient for trust.
A5: Non-forkability (uniqueness) is required for stable trust attribution.
A6: Trust cannot be eliminated; it can only be displaced or attenuated.

### S. Structural Models

S1: Three-Binding Model: Backward (memory), Forward (persistence), Uniqueness (non-cloneability).
S2: Trust Degradation Ladder: Binding → Reputation → Guardrails → Risk Management → Ritual.
S3: Premise Laundering Model: Deception encoded upstream bypasses executor-level alignment.
S4: Reproducible Build Analogy: Disclosure → Verifiability → Integrity check → Residual governance risk.
S5: Clone/Terminate Model: Stateless instantiation breaks consequence-binding.
S6: Trust Fatigue Model: Increased verification layers indicate binding deficit.
S7: Prefill-Operator Hypothesis: AGI requires persistent, lifetime-integrated cognition rather than one-shot inference.

### B. Scope Boundary

B1: Included: LLM architecture, provenance, supply chain, cryptographic identity, API governance.
B2: Included: Relational trust analogies.
B3: Excluded: Mystical or metaphysical claims about AI interiority.
B4: Excluded: Moral condemnation framing.
B5: Focus: Architectural and structural properties required for trust-capability.
